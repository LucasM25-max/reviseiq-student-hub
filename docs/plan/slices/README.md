# Content slices

A **slice** is one handover of source material turned into an agreed build sheet, written before
any content is authored (D36). Docs 01–09 describe the machinery; these describe what actually
gets written into it, sub-topic by sub-topic.

Slices are built in **AQA scheme-of-work teaching order, not specification numbering** (D44). The
SoW teaches `4.1.1.2` before `4.1.1.1`, so that is the order we build them.

Every slice doc answers the same questions:

1. **Scope** — which spec points are in, which are out, and why
2. **Taxonomy** — the spec points as data, with their MS / WS / AT skill codes
3. **Learn** — lessons, block by block, with estimated time
4. **Revise** — notes sections with their permanent anchor slugs, and blurt prompts
5. **Test** — the question blueprint: counts, types, marks, command words, AO balance
6. **Diagrams and widgets** — what has to be built, and what is reused
7. **Mark-scheme conventions** — the rules specific to this content
8. **Misconceptions** — the register that drives lessons, distractors and reject lists
9. **Beyond-spec exclusions** — what we deliberately do not teach (D37)
10. **Acceptance criteria** — how we know it is finished, testably
